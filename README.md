An entry for the make.fun bounty **Invent a Word We Need**: coin one new
English word and define it in a single clear line.

## The word

**Alarmnesia** (n.) — the brief confusion on waking when your alarm rings
and you cannot remember what day it is or why it matters.

## How it works

`main.py` writes the word and its one-line definition to
`/output/entry.txt` (1–140 characters, per the bounty gate). Run it with:

```sh
python3 main.py
```
